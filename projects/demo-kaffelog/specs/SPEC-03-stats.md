# SPEC-03 — Stats and comparison view

## Purpose
Show what actually improves the coffee: rating over time per method, and a
"what changed?" diff between any two brews.

## Open questions
Minimum number of brews before a trend is shown (proposal: 5)? How to group
free-text bean names (exact match in v1, fuzzy later — see ADR-002)?

## Definition of Done
Stats view with per-method series, comparison view, best-brew card.
