# Coffee Log (demo project)

A tiny app for logging and rating your coffee brews — and the **demo project for
URD Forge**. It exists so you can see what a spec-driven project looks like in the
Forge UI: a concept, a half-finished roadmap, specs in different states, and a
decision log.

This project is deliberately frozen **mid-development**. Two phases are done, one
is in progress, two are not started. That is what your own projects will look like
most of the time — and what Forge is built to make visible.

## What to look at

- **CONCEPT.md** — what Coffee Log is and why (with a changelog Forge renders as a timeline)
- **ROADMAP.md** — phases and steps; checkboxes drive the progress bars
- **specs/** — five specs in different states (`done`, `in-progress`, `draft`) with dependencies
- **DOCS.md** — the ADR log: decisions made along the way, and why
- **CLAUDE.md** — the instructions an AI coding tool follows to keep this structure intact

## Try it

Open this project in URD Forge, then open the command window and ask Claude Code
to implement SPEC-03. Watch the roadmap and spec board update as files change.

*Note: application source code is intentionally omitted — this demo is about the
project files Forge reads, not about the app itself.*
