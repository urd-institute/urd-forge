# SPEC-02 — Brew logging UI

## Purpose
Entry form and brew list. Logging a brew must take under 20 seconds.

## Decisions
Form pre-fills from the previous brew of the same method (opinionated defaults).
Rating is one tap directly on the list. Search filters on beans and method.

## Definition of Done
Form, list, search and one-tap rating implemented and keyboard-accessible.
